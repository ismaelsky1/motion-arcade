description: Cria um novo jogo para o Motion Arcade usando o agente criador-de-jogos
---

Use a tool Agent com subagent_type "criador-de-jogos" para atender o seguinte pedido do usuário: $ARGUMENTS

Se o usuário não tiver passado nenhum detalhe (argumento vazio), invoque o agente mesmo assim e deixe que ele conduza o levantamento de requisitos (ideia do jogo, mecânica, controle por mão/corpo, etc.) diretamente com o usuário.
